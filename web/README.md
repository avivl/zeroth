# web

Vite + React UI for the local daemon.

Stage 1 is single-player and talks to `zerothd` on the same machine. [Beautiful UI](https://www.beautifului.dev/) (MIT) is the intended primitive kit; it is not wired up in this skeleton.

```bash
task web
```

Or, from this directory, `pnpm install` and `pnpm run dev`. Lint is `pnpm run lint` (`tsc -b`), also run by `task lint` from the repo root.
